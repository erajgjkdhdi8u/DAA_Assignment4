# DAA Assignment 4

Dynamic Programming and String Algorithms in Java.

This project has 3 Edit Distance methods (recursive, table, two rows) and 2 string search methods (Naive, KMP). It also has operation counters, tests and a small experiment.

## Requirements

- JDK 17 or newer
- Maven
- Python 3 with matplotlib (only needed to make the graphs again)

## Run

From the project folder:

```bash
mvn test
mvn compile exec:java -Dexec.mainClass=Experiment
```

The second command creates `results/results.csv` again. It measures each input 5 times. The random generator uses seed 42. The operation counts are reproducible; timing can change a little between runs and computers.

To redraw the graphs:

```bash
pip install matplotlib
python plot_results.py
```

The three PNG charts are saved in `results/plots/`.

## Files

- `src/main/java/` - the algorithms, counters, generator and experiment
- `src/test/java/` - JUnit 5 tests
- `results/results.csv` - one row for each measured run
- `results/plots/` - three PNG graphs
- `REPORT.md` - experiment design and conclusions
